All easing modules should be parented to Animation.

```
Animation
├─── EaseInBack
├─── EaseInBounce
├─── EaseInCirc
├─── EaseInCubic
├─── EaseInExpo
├─── EaseInQuad
├─── EaseInQuart
├─── EaseInQuint
├─── EaseInSine
├─── EaseOutBack
├─── EaseOutBounce
├─── EaseOutCirc
├─── EaseOutCubic
├─── EaseOutExpo
├─── EaseOutQuad
├─── EaseOutQuart
├─── EaseOutQuint
├─── EaseOutSine
└─── Lerp
```
